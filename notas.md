### Dia 3 - 9 oct
hoy aprendi a usar input,  tambien  que en Python hay diferentes tipos de datos, hoy vi texto, numero y numero decima.  entendí que input recibe texto no importa como lo escribas y si quieres cambiar el texto a numero entero o decimal, tienes que usar float() o int() afuera del input para que el programa haga el cambio y asi poder crear formulas y presentar o interpretar los números como se debe en los reportes. otra cosa que aprendi fue un tercer tipo de error, valueerror que sale cuando el valor no sirve para la operación que estas haciendo. osea, cinco mil vs 5000. float() o int() pueden cambiar dígitos que entran como texto via input a números, pero no puede cambiar text que diga números ya que no son dígitos.
